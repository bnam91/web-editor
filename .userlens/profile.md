# Userlens 프로파일 — GODITOR (정본)

**왜 이 파일이 있나**: 없으면 `userlens-squad` 가 매번 «새 명세»를 만들어 **판정 기준이 실행마다 달라진다**
(변동성 재유입). 이 파일이 렌즈를 고정한다. ⛔여기 없는 축을 즉석에서 만들지 마라 — 필요하면 이 파일을 먼저 고친다.

**출처**: `ultraplan-2026-06-14.md` · `ultraplan-2026-06-15.md` · `report-*.md` 에서 «이미 통한» 방식만 뽑았다.
새로 발명한 항목은 없다.

## 1. 렌즈 — 네 갈래 (이 넷 밖은 이 스킬이 안 본다)

| 갈래 | 무엇 | 판정 기준 |
|---|---|---|
| **A 이상함** | 처음 쓰는 사람의 «기대 − 실제» 갭 | 기본값·가시성·라벨·위계가 «설명 없이» 납득되는가 |
| **B 기능갭** | Figma/Adobe 라면 당연한데 없는 것 | 스냅·단축키·분배·잠금 등. ⛔「있으면 좋겠다」가 아니라 «없어서 막힌다» |
| **C 버그** | «보이는데 안 남는 / 안 나가는 / 안 맞는» | L2 저장→재오픈 · L3 export · 줌 좌표 불변식 |
| **D 희귀버그** | 정상 순서엔 안 터지고 «이상한 순서»에서만 | 연타 · 중간취소 · 전환 중 조작 · autosave 경합 |

### ★이 렌즈가 «통한» 이유 (역설계 — 유지할 것)
> 「코드 기능 프로브」가 아니라 **«줌·스크롤·선택의 시스템 불변식을 의심»** 했기 때문에 잡혔다.
⇒ **기능 목록을 훑지 마라. 불변식을 의심해라.**

## 2. 불변식 (C·D 의 오라클 — 깨지면 결함)

```
L1 화면      조작 직후 화면이 «그 조작»을 반영한다
L2 저장·재오픈  flushSave → reload 후 «DOM + 메타»가 같다      ← 가장 많이 잡힌 층
L3 export    캔버스와 내보낸 산출물이 같다(누수·누락 없음)
L4 undo/redo  조작 → undo → redo 가 무손실
```
★**4겹 오라클**: C 갈래는 네 층을 «각각» 봐야 한다. 한 층만 보면 「화면은 맞는데 저장본이 다르다」를 놓친다.

## 3. 고정 규칙 (⛔실행마다 흔들리면 안 되는 것)

1. **⛔억지 채움 금지.** 카테고리가 목표 건수를 «정직하게» 못 채우면 **그 사실을 보고**한다. 가짜로 채우지 않는다.
2. **⛔기존 트래커 재보고 금지.** 이미 등재된 건은 다시 올리지 않는다(중복이 신규를 가린다).
3. **재현 필수.** C·D 는 «직접 재현»되지 않으면 올리지 않는다. 재현 못 하면 **「재현 못 함」으로 적는다** — 「없다」가 아니다.
4. **「0건」엔 양성대조.** 대조가 «살아 있음»을 보인 뒤에만 「0건」이 측정이다.
5. **격리 실행.** 전용 user-data-dir + 9350~9399 포트 + ⛔화면 밖(`--window-position=-2400,0`).
   ⛔현빈 실사용 9334·9345 / MCP매니저 9370·9372 / 툴매니저 9390·9392 접촉 금지.
6. **판정 전에 HEAD 를 찍는다.** 대상은 `git archive <해시>` **고정 스냅샷**으로 띄운다
   (남이 워크트리를 편집해도 안 움직인다 — 낡은 인스턴스로 판정한 사고가 있었다).
